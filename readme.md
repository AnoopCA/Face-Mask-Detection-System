# Face Mask Detection System

## Description

The Face Mask Detection System is a data science project that automates the detection of face masks in images and videos. This project aims to address the growing need for compliance monitoring during public health crises by leveraging machine learning and computer vision techniques.

## Features

- Implements OpenCV's CascadeClassifier with the pre-trained "face.xml" model for face detection.
- Analyzes image data for face mask detection with and without masks.
- Includes a convolutional neural network (CNN) for binary classification (mask/no mask).
- Real-time mask detection using a webcam or video feed.

## Technologies Used

### Programming Languages
- Python

### Libraries/Frameworks
- **Data Processing**: `pandas`, `numpy`
- **Visualization**: `matplotlib`, `seaborn`
- **Machine Learning**: `TensorFlow`, `Keras`
- **Computer Vision**: `OpenCV`
- **Tools**: `xml.etree.ElementTree` for XML parsing

## Data

The project uses a dataset of images with and without face mask.

### Source
Publicly available datasets such as Kaggle and Hugging Face.
